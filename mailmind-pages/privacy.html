Privacy Policy

Last updated: October 3, 2026

MailMind AI is a Chrome extension that generates AI-powered email replies inside Gmail. We are committed to protecting your privacy.

1. Information We Access

To generate reply suggestions, MailMind AI accesses:

  • The content of the email you currently have open in Gmail
  • Email attachments (PDF files and images) when you request attachment-aware replies

We access this data only when you actively click the "Generate Reply" button. We do not scan your inbox in the background.

2. How We Use Your Data

Email content is sent to our secure API server and then forwarded to Anthropic's Claude AI to generate a reply. The data is:

  • Processed in real-time only
  • Never stored on our servers
  • Never used for training AI models
  • Never shared with third parties except Anthropic (for AI processing)
  • Immediately discarded after the reply is generated

3. Google API Scopes & Usage

MailMind AI uses the following Gmail API scopes:

  • gmail.readonly — Read the content of the currently open email to generate an AI reply. We cannot send, modify, or delete any emails.
  • gmail.addons.current.message.readonly — Access the currently open message in the Gmail sidebar panel.

Our use of data received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

4. Data Protection Mechanisms

We implement the following technical and organizational measures to protect your data:

  • Encryption in Transit — All data is transmitted using TLS 1.3 encryption
  • No Persistent Storage — Email content is never written to disk or database. It exists only in memory during processing and is immediately discarded
  • Minimum Privilege — We request only the minimum OAuth scopes required for core functionality
  • No Email Content Logging — We do not log, cache, or retain any email content on our servers
  • AI Processing Isolation — Email content sent to Anthropic Claude API is not used for model training per Anthropic's API Terms
  • No Third-party Advertising — Email content is never shared with advertisers or analytics providers

5. Data Storage

We store only the following locally in your browser:

  • Your subscription status (Free or Pro)
  • Daily usage count
  • A randomly generated user ID for rate limiting

6. Third-Party Services

  • Anthropic Claude API — AI processing
  • Cloudflare — API hosting and security
  • Paddle — Payment processing

7. Your Rights

  • Revoke Gmail access at any time via Google Account Permissions
  • Uninstall the extension at any time
  • Request deletion of your account data by contacting us
