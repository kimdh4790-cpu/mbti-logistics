# /steelman — 주장 강화 (최선의 버전)

내 주장·아이디어를 가장 강력한 형태로 다시 만듭니다.
투자자 설득, 제안서, 경쟁사 대응 논리에 활용합니다.

## 사용법
```
/steelman <주장 또는 아이디어>
```

## 강화 방식

1. **핵심 논거 선별**: 가장 강력한 이유 3개만 추출
2. **데이터·증거 보강**: 수치, 사례, 시장 근거 추가
3. **반론 선점**: 예상 반박을 먼저 다루고 반박
4. **감정 호소 제거**: 논리·사실 중심으로 재구성
5. **결론 명료화**: 행동 요청(CTA)이 뚜렷하게

## 출력

**강화된 주장**:
[재구성된 논리 전문]

**핵심 근거 TOP 3**:
1. ...
2. ...
3. ...

**예상 반론 & 재반박**:
- 반론: ... → 재반박: ...

$ARGUMENTS
