# /5whys — 버그 근본 원인 분석

버그나 장애의 증상을 받아서 "왜?"를 5번 파고들어 근본 원인과 재발 방지책을 찾습니다.

## 사용법
```
/5whys <증상 또는 버그 설명>
```

## 실행 방식

1. **1차 왜**: 표면 증상에서 직접 원인 도출
2. **2차 왜**: 그 원인이 생긴 이유
3. **3차 왜**: 구조적·설계적 원인
4. **4차 왜**: 프로세스·습관적 원인
5. **5차 왜**: 근본 원인 (시스템·조직·설계 수준)

## 출력 형식

```
증상: ...

왜 1: ...
왜 2: ...
왜 3: ...
왜 4: ...
왜 5 (근본): ...

근본 원인 요약: ...
재발 방지 조치: ...
관련 파일/코드: ...
```
