# /critique — 코드·설계 약점 진단

코드, 설계, API 구조의 약점을 솔직하게 찾아서 개선 방향을 제시합니다.

## 사용법
```
/critique <파일명 또는 기능 설명>
```

## 진단 관점

1. **논리 오류**: 엣지케이스, null 처리, 타입 불일치
2. **보안**: 인증 누락, 입력 검증, 시크릿 노출
3. **성능**: 불필요한 Firestore 읽기, N+1 쿼리, 리스너 누수
4. **유지보수성**: 중복 코드, 전역변수 충돌, 함수 책임 범위
5. **CLAUDE.md 규칙 위반**: 절대 금지 항목 위반 여부
