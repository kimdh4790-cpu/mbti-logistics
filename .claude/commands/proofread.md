# /proofread — 맞춤법·문장 교정

한국어 맞춤법, 띄어쓰기, 어색한 표현을 교정합니다.
마케팅 자료, 블로그, 공지문 최종 검수에 사용합니다.

## 사용법
```
/proofread <교정할 글>
```

## 검수 항목

1. **맞춤법·띄어쓰기**: 표준국어대사전 기준
2. **외래어 표기**: 국립국어원 외래어표기법 (예: 카페 O, 까페 X)
3. **어색한 번역투**: "~의 경우", "~에 있어서" 등 제거
4. **중복 표현**: "역전 앞", "미리 예약" 등 제거
5. **숫자·단위 표기**: 1,000원 / 100명 / 3개월 통일

## 출력

**수정 내역**:
| 원문 | 수정 | 이유 |
|---|---|---|
| ... | ... | ... |

**교정 완료본**:
[수정된 글]

$ARGUMENTS
