# /margin — 마진·수익성 분석

제품·서비스·메뉴의 마진율과 수익성을 계산하고 개선 방향을 제시합니다.
FILO 마진분석, DONWAY 요금제, 용차앱 수수료 구조 분석에 활용합니다.

## 사용법
```
/margin <제품명 또는 구조 설명>
```

## 분석 항목

| 항목 | 값 | 계산 방법 |
|---|---|---|
| 판매가 | ○○원 | 입력값 |
| 원가 (COGS) | ○○원 | 재료비+인건비+기타 |
| 매출 마진 | ○○% | (판매가-원가)/판매가×100 |
| 손익분기점 | ○○건/월 | 고정비/건당 마진 |
| 목표 마진율 | ○○% | 업종 평균 기준 |

**현재 마진율 평가**: [낮음/보통/양호] (업종 평균: 외식업 60~70%, SaaS 70~85%)

**개선 방향**:
- 원가 절감 가능 항목: ...
- 가격 인상 여력: ...
- 볼륨 확대 전략: ...

$ARGUMENTS
