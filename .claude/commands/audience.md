# /audience — 독자 맞춤 글쓰기

같은 메시지를 특정 독자층에 맞게 재작성합니다.
FILO·DINE·DONWAY·용차앱 각 타겟에 최적화합니다.

## 사용법
```
/audience <타겟 유형> <원문 또는 내용 설명>
```

## 타겟 유형 예시

| 타겟 | 핵심 관심사 | 언어 스타일 |
|---|---|---|
| `소상공인` | 비용 절감, 손쉬운 사용, 직원 관리 | 친근, 실용적 |
| `배달대행사장` | 기사 정산 정확성, 시간 절약 | 직접적, 숫자 중심 |
| `물류기사` | 수수료 없음, 직접 연결, 수입 보장 | 단도직입 |
| `식당사장` | 매출 분석, 재고, QR 주문 | 실무 중심 |
| `카페사장` | 테이블 POS, 직원 스케줄, 간편함 | 감성+실용 |
| `투자자` | 시장 규모, 성장성, 차별화 | 데이터·논리 중심 |

$ARGUMENTS
