# /pros-cons — 장단점 분석표

결정·아이디어·제품의 장단점을 빠르게 표로 정리합니다.
비즈니스 의사결정, 기능 도입 여부 검토에 활용합니다.

## 사용법
```
/pros-cons <분석할 대상>
```

## 출력 형식

**대상**: [분석 대상]

| 항목 | 장점 | 단점 |
|---|---|---|
| 비용 | ... | ... |
| 운영 | ... | ... |
| 고객 경험 | ... | ... |
| 리스크 | ... | ... |
| 확장성 | ... | ... |

**종합 판단**: [도입 권장 / 조건부 권장 / 재검토 필요] — 이유 1~2줄

**핵심 변수**: 이 결정을 바꿀 수 있는 조건 (예: 월 MAU 500 초과 시 재검토)

$ARGUMENTS
