# /ad-brief — 제품 광고 브리프 즉시 생성

MBTICO 제품(FILO/DONWAY/용차앱/MBTICO) 광고를 만들 때 필요한 브리프를 즉시 뽑아줍니다.
Higgsfield, CapCut, 영상 편집 툴에 바로 사용 가능합니다.

## 사용법
```
/ad-brief <제품명> [유형: 비포애프터/ugc/제품샷/비교/스토리] [플랫폼: 인스타/유튜브/틱톡]
```

## 출력 구조

### 광고 기본 정보
| 항목 | 내용 |
|---|---|
| 제품 | ... |
| 유형 | ... |
| 플랫폼 | ... |
| 영상 길이 | 15s / 30s / 60s |
| 해상도 | 720p (시안) → 1080p (최종) |

### 훅 (첫 3초) — 3개 옵션
1. **질문형**: "..."
2. **숫자형**: "..."
3. **공감형**: "..."

### 본문 스크립트 (10~25초)
```
[시각]: [내레이션/자막]
0s: 훅
3s: 페인포인트 확인
8s: 솔루션 등장
15s: 결과/증거
22s: CTA
```

### Higgsfield 프롬프트 (복사해서 바로 사용)
```
[720p 시안용 한 줄 지시]
```

### 글로벌 확장 버전 (선택)
- 영어 버전 훅: "..."
- 일본어 버전 훅: "..."
