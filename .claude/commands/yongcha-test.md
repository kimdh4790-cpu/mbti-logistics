# 용차앱 (yongcha.app) 전체 기능 점검 및 버그 수정

## ⚠️ 절대 건드리면 안 되는 것들
- `wrangler.toml` — 수정 금지 (Cloudflare Secrets 날아감)
- `firestore.rules` — 기존 yongcha 권한 구조 유지
- `_worker.js` — 라우팅 구조 변경 금지 (donway/filo/dine/yongcha 공존)
- Firebase 컬렉션명 — yongcha_users / yongcha_posts / yongcha_applies / yongcha_settlements / yongcha_reviews

## 리팩토링 완료 확인 (건드리지 말 것)
- `yongcha.html` — 메인 앱 (회원가입/로그인/대시보드/공고/검색/채팅/평가/관리자)
- Firebase Auth, Firestore onSnapshot 실시간 연동
- FCM 알림 (새 지원자/배차확정/승인/미선발/긴급공고)
- 양방향 평가 시스템 (대리점↔기사)
- 신뢰점수 + 등급 뱃지
- 관리자 대시보드

## 점검 및 수정 대상 기능

### 1. 회원 관리
- 대리점/기사 구분 회원가입 정상 작동 확인
- 프로필 수정 저장 확인
- 신뢰점수 계산 및 등급 뱃지 표시 확인

### 2. 노선 공고 (대리점)
- 공고 등록 (택배사/구역/단가/물량/차량/시간/정산일) 확인
- 공고 상태 관리 (모집중→운행중→완료) 확인
- 지원자 확인 + 승인/미선발 확인
- 중복 공고 방지 로직 확인

### 3. 노선 검색 (기사)
- 전체/택배사/지역 필터 확인
- 긴급/인증대리점 필터 확인
- D-day 배지 + 정렬 확인
- 기사 맞춤 추천 정렬 확인

### 4. 배차 확정 흐름
- 승인 → FCM 알림 확인
- 채팅방 자동 생성 확인
- 기사 전화번호 공개 확인
- 출근 확정 버튼 확인

### 5. 구인구직 탭
- 정규직 채용공고 등록 확인
- 기사 이력서 등록 확인
- 이력서 찾기 (대리점) 확인

### 6. 일일 건수 + 정산
- 기사 일일 건수 입력 확인
- 주간 누적 자동 계산 확인
- 대리점 확인·승인 확인

### 7. 채팅
- 1:1 채팅 실시간 onSnapshot 확인
- 읽지 않은 메시지 수 확인

### 8. FCM 알림
- 새 지원자 / 배차확정 / 승인·미선발 / 긴급공고 알림 확인

### 9. 양방향 평가
- 노선 종료 후 평가 트리거 확인
- 공고정확도 평가 (허위공고 방지) 확인

### 10. 관리자 대시보드
- 통계 / 회원 정지 / 공고 강제 마감 / 프리미엄 배지 확인

## 미구현 (건드리지 말 것 — 추후 개발)

## 시장조사 기반 추가 기능 (우선순위 순)

### 조사 대상 앱/서비스
- 크몽, 숨고 (프리랜서 매칭 UX 참고)
- 쿠팡이츠/배민 (기사 앱 UX 참고)
- 카고매니저, 화물맨 (화물 매칭 앱 경쟁사)
- 당근마켓 (지역 기반 신뢰 시스템 참고)

### 추가할 기능 (사용자 편의 중심)
1. **공고 북마크/찜** — 기사가 관심 공고 저장
2. **노선 지도 미리보기** — 구역 대략적 위치 표시 (정적 지도 이미지)
3. **단가 시세 배지** — "이 지역 평균보다 높음/낮음" 표시
4. **빠른 지원** — 원클릭 지원 (이력서 자동 첨부)
5. **공고 알림 구독** — 특정 지역/택배사 공고 등록 시 즉시 FCM
6. **대리점 프리뷰 카드** — 공고 클릭 전 대리점 평점/후기 수 미리보기
7. **기사 포트폴리오** — 완료 노선 수/평점/택배사 경력 자동 생성
8. **일정 캘린더** — 기사의 노선 시작/종료일 캘린더 뷰
9. **공고 공유** — 카카오톡/링크 공유 기능
10. **대리점 인증 마크** — 사업자번호 인증 완료 표시

### UI/UX 개선 원칙
- 모바일 퍼스트 (기사는 99% 폰으로 사용)
- 터치 영역 최소 48px
- 로딩 스켈레톤 UI (빈 화면 방지)
- 핵심 액션은 하단 고정 버튼
- 알림 배지 항상 눈에 띄게
- 다크모드 지원

### 작업 방식
- 기존 코드 리팩토링 구조 유지
- 새 기능은 기존 함수 네이밍 규칙 따름
- wrangler.toml 절대 수정 금지
- 배포 후 yongcha.app 실제 테스트 필수


## 디자인 방향 — 경쟁사 대비 월등히 우수하게

### 경쟁사 디자인 현황 (약점)
- 화물맨, 카고매니저: 2010년대 UI, 텍스트 나열 위주, 촌스러운 색상
- 카카오오픈채팅/네이버카페: 구조 없음, 검색 불편, 모바일 최적화 안됨

### 용차앱 디자인 목표
- **프리미엄 다크 테마** 기본 (배달기사 야간 사용 많음)
- **카드형 공고** — 한눈에 핵심 정보 (단가/구역/D-day/인증뱃지)
- **네이버 스마트스토어급 신뢰 UI** — 평점/후기수/인증마크 강조
- **당근마켓급 심플함** — 불필요한 요소 제거, 핵심만
- **쿠팡이츠 기사앱급 UX** — 원탭 지원, 빠른 확인, 알림 즉각 반응

### 디자인 시스템
- 메인 컬러: #1a1a2e (다크 네이비) + #00d4aa (민트 강조색)
- 서브 컬러: #16213e (카드 배경) + #0f3460 (섹션 구분)
- 폰트: 굵고 명확하게, 핵심 수치(단가/건수) 크게 강조
- 아이콘: 라인 아이콘 통일 (lucide 스타일)
- 카드 반경: 16px, 그림자 부드럽게
- 하단 탭바: 5탭 (홈/공고/채팅/내노선/프로필)
- 공고 카드: 택배사 로고 + 구역 + 단가 + D-day 뱃지 + 인증마크
- 로딩: 스켈레톤 애니메이션 (회색 펄스)
- 전환 효과: 슬라이드 업 애니메이션

- 실제 기사/대리점이 첫눈에 "오 이거 쓰고 싶다" 느낌
- 박람회(8/20~22 벡스코) 데모용으로 완성도 높게
