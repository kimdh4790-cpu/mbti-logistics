# /tweet — 핵심 한 줄 SNS 문장

긴 내용을 SNS(인스타·스레드·X)용 임팩트 있는 짧은 문장으로 압축합니다.
해시태그 포함, 모바일 첫 줄에서 멈추게 만드는 것이 목표.

## 사용법
```
/tweet <내용 또는 키워드>
```

## 출력

5가지 버전 제공:

1. **질문형**: [?로 끝나는 후킹 문장]
2. **사실형**: [숫자·데이터 포함 한 줄]
3. **공감형**: [독자 감정에 닿는 문장]
4. **혜택형**: [명확한 이득 제시]
5. **역발상형**: [상식을 뒤집는 문장]

해시태그: #FILO #소상공인POS #식당창업 (주제에 맞게 자동 생성)

$ARGUMENTS
