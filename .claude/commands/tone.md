# /tone — 말투 전환

같은 내용을 다른 말투·채널에 맞게 변환합니다.
SNS, 공식 제안서, 블로그 등 용도에 따라 즉시 재작성합니다.

## 사용법
```
/tone <말투 유형> <원문>
```

## 지원 말투 유형

| 유형 | 설명 | 주요 채널 |
|---|---|---|
| `casual` | 편하고 친근한 구어체 | 카카오채널, 인스타 |
| `formal` | 격식체, 존댓말 | 제안서, 공문, 이메일 |
| `sns` | 짧고 임팩트 있게 (해시태그 포함) | 인스타, 유튜브 쇼츠 설명 |
| `blog` | 정보 전달 중심, 소제목 포함 | 네이버 블로그, 브런치 |
| `sales` | 혜택 강조, CTA 포함 | 랜딩페이지, 문자 |
| `story` | 사례·스토리 형식 | 뉴스레터, 유튜브 스크립트 |

## 출력

**[유형] 버전**:
[변환된 글]

$ARGUMENTS
