# /outline — 목차·구성 잡기

글·영상·제안서의 뼈대 구조(목차)를 잡아줍니다.
작성 시작 전에 방향을 먼저 잡을 때 사용합니다.

## 사용법
```
/outline <주제> [형식: 블로그/제안서/영상스크립트/보고서]
```

## 출력 형식

**[주제] [형식] 목차**

1. [섹션명] — [핵심 내용 한 줄, 예상 분량]
   - 1-1. [소제목]
   - 1-2. [소제목]
2. [섹션명] — ...
3. ...

**총 분량 예상**: ○○자 / ○○분 읽기

**독자 여정**: [독자가 처음부터 끝까지 느끼는 흐름 한 줄]

$ARGUMENTS
