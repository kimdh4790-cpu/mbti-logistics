# /devil — 악마의 변호인 (반박 찾기)

내 계획·주장에서 숨은 약점과 반박을 먼저 찾아냅니다.
출시 전 전략 점검, 투자 제안서 약점 보완에 활용합니다.

## 사용법
```
/devil <계획 또는 주장>
```

## 반박 탐색 범위

1. **가정 오류**: 당연하다고 전제한 것 중 틀린 것
2. **시장 현실**: 실제 고객이 다르게 행동할 가능성
3. **경쟁 반응**: 경쟁사가 즉시 따라 할 수 있는 것
4. **실행 위험**: 계획대로 되지 않을 현실적 이유
5. **비용·수익**: 숨겨진 비용, 과대평가된 수익
