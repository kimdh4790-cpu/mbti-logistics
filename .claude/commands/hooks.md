# /hooks — 후킹 첫 문장 5개

콘텐츠·광고·SNS 포스팅의 첫 문장(후크)을 5가지 각도로 만듭니다.
독자가 멈추고 읽게 만드는 것이 목표입니다.

## 사용법
```
/hooks <제품명 또는 주제>
```

## 후크 유형 5가지

1. **질문형** — "왜 ○○ 매장은 직원 급여를 매달 수작업으로 계산할까요?"
2. **통계·숫자형** — "소규모 외식업 폐업 원인 1위: 인건비 오계산"
3. **공감형** — "월말마다 엑셀 열고 한숨부터 쉬신다면..."
4. **역발상형** — "POS 기계 없이도 매장 관리가 된다고요?"
5. **긴박형** — "지금 이 순간도 직원 초과근무 수당이 잘못 계산되고 있습니다"
