# /compare — 비교표 생성

두 가지 이상 옵션을 비교하는 표를 만듭니다.
경쟁사 비교, 요금제 비교, 기술 선택 비교에 활용합니다.

## 사용법
```
/compare <옵션A> vs <옵션B> [비교 기준 키워드]
```

## 출력 형식

| 항목 | [옵션A] | [옵션B] |
|---|---|---|
| 가격 | ... | ... |
| 기능 | ... | ... |
| 사용 난이도 | ... | ... |
| 계약 조건 | ... | ... |
| 지원 | ... | ... |
| 적합 대상 | ... | ... |
