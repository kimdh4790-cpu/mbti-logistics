# /ad-remix — 잘되는 광고 분석 + 리메이크 버전 기획

검증된 광고(경쟁사/레퍼런스)를 분석해서 우리 제품에 맞는 변형 버전을 기획합니다.
Higgsfield MCP가 연결된 경우 곧바로 영상 생성까지 이어집니다.

## 사용법
```
/ad-remix <레퍼런스 광고 URL 또는 설명> [우리 제품: filo/donway/yongcha/mbtico]
```

## 분석 → 리메이크 순서

### STEP 1. 광고 구조 해체 (검증된 것만 남기기)
분석할 항목:
- **훅 (첫 3초)**: 시청자를 멈추게 만드는 장치 (질문/충격/숫자/공감)
- **구조 유형**: 비포애프터 / UGC / 제품샷 / 스토리 / 비교
- **타겟 페인포인트**: 어떤 불편함을 건드리는가
- **CTA**: 행동 유도 방식 (할인/무료체험/지금신청)
- **비주얼 톤**: 색감, 캐릭터, 배경, 속도감

### STEP 2. 우리 제품용 리메이크 기획 (2개 유형)

**버전 A**: 같은 구조 + 다른 훅
| 항목 | 원본 | 리메이크 |
|---|---|---|
| 훅 | ... | ... |
| 페인포인트 | ... | ... |
| 비주얼 | ... | ... |
| CTA | ... | ... |

**버전 B**: 다른 구조 + 같은 페인포인트

### STEP 3. Higgsfield 프롬프트 (2개)
```
버전 A 프롬프트: [Higgsfield에 바로 붙여넣을 한 줄 지시]
버전 B 프롬프트: [Higgsfield에 바로 붙여넣을 한 줄 지시]
```

### STEP 4. 피칭 문구 (해당 기업에 보낼 때)
```
"[제품명]의 [광고명] 잘 돌아가고 있죠?
이 구조를 [새 시장/새 각도]에 맞게 리메이크해봤습니다.
더 보고 싶으시면 연락 주세요."
```
