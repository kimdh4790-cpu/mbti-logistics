# /expand — 내용 늘리기

짧은 글이나 개요를 완성도 있는 긴 글로 확장합니다.
블로그 포스트, 제안서, 제품 소개 등에 활용합니다.

## 사용법
```
/expand <짧은 글 또는 개요> [목표 분량: 블로그/제안서/SNS캡션]
```

## 확장 방식

- **배경 추가**: 왜 이 주제가 중요한지 컨텍스트 제공
- **사례 삽입**: 구체적 수치·스토리로 주장 뒷받침
- **반론 처리**: 독자 의구심을 선제적으로 해소
- **섹션 구조화**: 소제목으로 스캔 가능하게
- **CTA 강화**: 마지막에 행동 유도 문장 추가

## 출력

[확장된 글 전문]

**분량**: 약 ○○자 / ○○단어

$ARGUMENTS
