# /story — 사례 스토리로 풀기

제품·기능을 실제 사용자 사례 형식의 스토리로 변환합니다.
"Before → 문제 → After" 구조로 공감을 유도합니다.

## 사용법
```
/story <제품명 또는 기능> [대상 고객 유형]
```

## 스토리 구조

**등장인물**: [직업, 매장 규모, 고민]

**Before (도입 전)**
> [고통 상황을 구체적으로 묘사. 숫자·시간·감정 포함]

**전환점**
> [어떻게 제품을 알게 됐는지]

**After (도입 후)**
> [달라진 점. 절약한 시간, 줄어든 비용, 생긴 여유]

**한 줄 소감**
> "[인물 이름]씨: ..."
