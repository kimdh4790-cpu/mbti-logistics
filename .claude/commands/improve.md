# /improve — 글 개선

글의 설득력·명확성·가독성을 개선합니다.
문제점을 먼저 짚고 즉시 수정된 버전을 제공합니다.

## 사용법
```
/improve <개선할 글>
```

## 개선 항목

1. **명확성**: 모호한 표현 제거, 주어·서술어 명확화
2. **설득력**: 주장에 근거 추가, 혜택 구체화
3. **가독성**: 문장 길이 조정, 단락 구조화
4. **CTA**: 독자가 취할 행동이 명확한지 확인

## 출력

**발견된 문제**:
- [문제 1]
- [문제 2]

**개선된 버전**:
[수정된 글]

**변경 요약**: [무엇을 왜 바꿨는지 한 줄]

$ARGUMENTS
