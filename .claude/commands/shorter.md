# /shorter — 글 줄이기

글을 의미 손실 없이 최대한 짧게 압축합니다.
SNS 캡션, 알림문자, 버튼 라벨 등 공간 제약이 있을 때 사용합니다.

## 사용법
```
/shorter <줄일 글> [목표 글자수]
```

## 압축 원칙

- 접속사·수식어 제거 (그러나, 또한, 매우, 정말)
- 반복 표현 1회로 통합
- 수동태 → 능동태 변환
- 긴 관계절 → 명사구로 전환
- 핵심 주장 1개만 남기기

## 출력

**원문** (○○자): [원문]
**압축본** (○○자): [압축된 글]
**삭제 항목**: [무엇을 왜 뺐는지 한 줄]

$ARGUMENTS
