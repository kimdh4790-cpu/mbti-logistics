# /ghost — AI 티 없애기 (자연스럽게 다듬기)

AI가 쓴 티 나는 글을 사람이 직접 쓴 것처럼 다듬습니다.
틀에 박힌 표현, 과도한 나열, 어색한 문장을 제거합니다.

## 사용법
```
/ghost <다듬을 글>
```

## 다듬는 항목

- "물론", "당연히", "결론적으로", "첫 번째로" 등 AI 틱한 접속사 제거
- 3개 이상 나열("A, B, C, 그리고 D") → 핵심 1~2개로 압축
- 수동태 → 능동태 전환
- 딱딱한 명사형 종결("~합니다") → 자연스러운 구어체 혼합
- 문단 길이 불균형 교정

## 출력

**원문 문제점**: (짧게)
**다듬은 버전**:
[수정된 글]

$ARGUMENTS
