## 각 브랜드 파일 위치
`.claude/skills/awesome-design-md/design-md/[브랜드명]/DESIGN.md`

## 사용 방법
작업 시 해당 브랜드 DESIGN.md를 읽어 색상 팔레트·타이포그래피·컴포넌트 스타일을 적용한다.

예시: Stripe 스타일 결제 UI 요청 시 → `design-md/stripe/DESIGN.md` 참조
예시: Notion 스타일 대시보드 요청 시 → `design-md/notion/DESIGN.md` 참조
예시: MBTICO 브랜드(네이비+골드)와 유사한 참조 → `design-md/stripe/DESIGN.md` 또는 `design-md/linear.app/DESIGN.md`
