## 핵심 원칙 요약 (18가지 → 4개 카테고리)

| 카테고리 | 핵심 심리 | 대표 원칙 |
|---|---|---|
| 믿게 만들기 | 구체 숫자·사회적 증거·권위 | "500명 정산 3분" / "기사 2천명 이미 사용" |
| 내 얘기로 만들기 | 자기관련성·목표관련성 | "화물 소장님이라면" / "정산 담당자시면" |
| 판돈 키우기 | 손실회피·부정성 편향 | "모르면 수수료 30% 계속 냄" |
| 정보 숨기기 | 호기심 격차·열린 고리 | "이거 알면 주선사 다시 안 씁니다" |

---

## 스토리텔링 7단계 구조 (영상 1분 기준)

| 단계 | 시점(초) | 내용 |
|---|---|---|
| 1. 인사이트로 시작 | 0~5 | 결론/교훈 먼저, 배경 설명 나중 |
| 2. 하나의 아이디어 | 5~10 | 이 영상이 증명하는 것 딱 하나 |
| 3. 성찰로 말하기 | 10~25 | 느낌이 아니라 배운 것 공유 |
| 4. 대조 보여주기 | 25~40 | Before vs After, 이전 vs 이후 |
| 5. 절반으로 줄이기 | 40~50 | 교훈과 무관한 디테일 제거 |
| 6. 시청자를 주인공으로 | 50~55 | "소장님이라면?" / "담당자시면?" |
| 7. 다른 각도로 반복 | 55~60 | 같은 핵심 메시지, 다른 표현으로 마무리 |

### 용차앱 (yongcha.app)
**핵심 메시지**: 주선사 없이 소장·기사 직접 거래

| 유형 | 후크 문장 | 적용 원칙 |
|---|---|---|
| 손실회피 | "수수료 30% 내고 계신 거, 알고 계셨나요?" | 손실회피 + 자기관련성 |
| 호기심 격차 | "이거 아시면 다시는 주선사 안 씁니다" | 호기심 격차 |
| 사회적 증거 | "소장님 2,000명이 이미 직접 거래 중입니다" | 사회적 증거 |
| 대조 | "주선사 끼면 30% 손해, 안 끼면 0원" | 대조 |
| 경고 | "이거 모르면 매달 수십만원 날립니다" | 부정성 편향 |
| 예측 오류 | "AI가 기사 매칭하면 더 비쌀 것 같죠? 반대입니다" | 예측 오류 |
| 공감 | "빈차 잡느라 전화 돌리다 지치셨죠?" | 자기관련성 |
| 숫자+결과 | "소장 월 50만원 절약, 기사 단가 15% 상승" | 구체성 |

**추천 오프닝 (60초 영상)**
> "수수료 30% 내고 계신 거 알고 계셨나요?

## 후크 생성 프롬프트 (Claude/ChatGPT용)

```
너는 조회수 100만 이상을 만든 숏폼 카피라이터야.

[내 주제]: ___
[타깃 시청자]: ___
[영상에서 전달할 핵심 메시지]: ___

위 정보를 바탕으로 릴스 첫 3초에 쓸 후크 문장 20개를 만들어줘.

조건:
- 한 문장은 20자 이내, 소리 내어 읽었을 때 자연스러운 구어체
- 호기심형 5개 / 공감형 5개 / 경고형 5개 / 숫자·결과형 5개로 나눠서
- 과장이나 거짓 정보 없이, 영상 내용으로 지킬 수 있는 약속만
- 각 문장 옆에 왜 효과적인지 한 줄 이유 추가
```

## 후크 적용 원칙 (실전)

1. **정답 절반만 보여줘라** — 다 말하면 볼 이유 없고, 아무것도 안 말하면 클릭 이유 없음
2. **약속한 건 반드시 지켜라** — 후크 과장은 이탈률 올려서 다음 영상이 안 퍼짐
3. **화면 자막 = 첫 대사** — 무음 시청자가 절반 이상
4. **제품 설명보다 문제부터** — "DONWAY입니다" X → "정산 3분이면 끝납니다" O
5. **숫자는 정확하게** — "빠르게" X → "3분이면" O
