## 상품 소개 (인프런 클립 등록용)

### 이걸 만들게 된 계기

카페 사장님이 이런 말을 했습니다.

_"리뷰 답글 달아야 한다는 건 아는데, 바쁘다 보면 며칠 씩 지나가요. 그러다 리뷰가 쌓이면 더 답장하기 싫어지고..."_

리뷰 관리가 중요한 걸 알면서도 못 하는 이유는 단 하나, **시간이 없어서**입니다.

저는 이걸 자동화로 해결했습니다.

---

### 이 패키지로 무엇을 할 수 있나요?

네이버 플레이스·카카오맵에 새 리뷰가 올라오면 30분 안에 사장님 휴대폰으로 알림이 옵니다.
알림에는 **ChatGPT가 작성한 맞춤 답글 초안**이 함께 포함됩니다.

사장님은 복사 → 붙여넣기만 하면 됩니다.

**대상 사용자:**
- 네이버 플레이스·카카오맵 리뷰 관리가 버거운 소상공인
- 리뷰 답글을 꼭 달고 싶지만 매번 뭘 써야 할지 막막한 분
- ChatGPT를 활용하고 싶지만 어디서 시작해야 할지 모르는 분
- n8n으로 업무 자동화를 처음 시도해보고 싶은 분

---

### 실제 수치로 보는 효과

| 항목 | 기존 방식 | 이 패키지 사용 후 |
|---|---|---|
| 새 리뷰 확인 주기 | 수동 확인 (잊어버리면 며칠) | **30분마다 자동** |
| 답글 초안 작성 시간 | 5~10분 | **즉시 (자동 생성)** |
| 월 리뷰 관리 시간 | 2~3시간 | 15분 (복붙만) |
| 서버 비용 | — | 월 0원 (Oracle Cloud 무료) |
| ChatGPT 비용 | — | 리뷰 1건당 약 ₩5 |

---

### 포함 내용

1. **n8n 워크플로우 1개** (`workflow-04-review-alert.json`)
   - 30분마다 네이버 플레이스·카카오맵 리뷰 자동 수집
   - ChatGPT(gpt-4o-mini)로 고객 이름·리뷰 내용 반영한 맞춤 답글 초안 생성
   - 사장님 휴대폰으로 리뷰 원문 + 답글 초안 문자 발송

2. **설치 가이드** (`review-guide.md` → PDF 변환)
   - Oracle Cloud 서버 접속부터 첫 알림 수신까지 단계별 안내
   - 네이버/카카오 장소 ID 찾는 방법 스크린샷 포함
   - 자주 묻는 질문 포함
