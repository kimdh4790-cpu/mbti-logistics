# 인프런 클립 상품 설명 — n8n 카카오 알림톡 자동화 패키지

---

## 상품 제목 (후보 3개 중 선택)

**A안** (직접적): `n8n으로 카카오 알림톡 자동화 — 구글 시트 연동 완전 자동 발송 패키지`  
**B안** (소상공인 타겟): `월 0원 서버로 카카오 알림톡 자동화 — 정산·예약·알림 자동 발송 워크플로우 3종 + 설치 가이드`  
**C안** (자극적): `개발자 없이 카카오 알림톡 정산 자동화 — n8n 워크플로우 바로 쓰는 패키지`

> 추천: **B안** — "월 0원 서버"가 클릭률 높음. 소장·사장님이 첫 번째 걸리는 키워드.

## 상품 소개 (인프런 클립 등록용)

### 이걸 만들게 된 계기

배달대행 소장님 한 분이 매주 월요일 아침 2시간을 정산 카카오톡 보내는 데 쓰고 있었습니다.

기사 50명에게 일일이 금액 확인하고, 문자 복붙하고, 전송 누르는 작업을 반복했습니다.

저는 그걸 **n8n 워크플로우 하나로 4분 만에 끝냈습니다.**

---

### 이 패키지로 무엇을 할 수 있나요?

카카오 알림톡을 **직접 코딩 없이** 자동으로 발송하는 n8n 워크플로우 3개와 상세 설치 가이드를 제공합니다.

**대상 사용자:**
- 매주 정산 메시지를 수동으로 보내는 소장님·사장님
- 배달대행·택배 대리점에서 기사 정산을 담당하는 분
- 직원·고객에게 알림톡 자동 발송 시스템을 만들고 싶은 분
- n8n을 처음 써보지만 바로 쓸 수 있는 템플릿이 필요한 분

### 워크플로우 상세 설명

#### 워크플로우 1 — 첫 발송 테스트
API 키만 입력하면 바로 테스트 발송. 성공/실패 여부를 자동으로 확인합니다.  
처음 설치 후 5분 안에 첫 알림톡을 받아보실 수 있습니다.

#### 워크플로우 2 — 구글 시트 일괄 발송
구글 시트에 이름·휴대폰·정산 데이터를 입력하면 클릭 한 번에 전원 발송.  
1초 간격 자동 조절로 API 제한 없이 안전하게 처리합니다.

#### 워크플로우 3 — 매주 완전 자동화
매주 월요일 09:00에 자동 실행 → 지난주 데이터 조회 → 전원 발송 → 관리자 완료 알림.  
한 번 설정하면 이후 터치 없이 자동으로 돌아갑니다.

### 설치 환경

- n8n (무료 오픈소스) — Oracle Cloud / Docker / 자체 서버 모두 가능
- 알리고 계정 (aligo.in) — 무료 가입, API 키 발급
- 카카오 비즈니스 채널 + 알림톡 템플릿 (카카오 심사 1~3일)
- 구글 시트 (워크플로우 2·3만 해당)

---

### 이 패키지가 필요 없는 경우

구매 전 솔직하게 말씀드립니다.

- **카카오 채널이 없고 개설 의향도 없는 경우**: SMS 대체 방법은 가이드에 설명드리지만, 알림톡 전용 패키지입니다
- **1,000명 이상 대용량 동시 발송이 주목적인 경우**: 알리고 1회 1,000명 제한이 있어 대형 발송사업에는 부적합합니다
- **n8n 설치조차 하기 싫으신 경우**: README에 설치 가이드를 단계별로 담았지만, 최초 설정에 30~60분 시간이 필요합니다
- **카카오 알림톡 템플릿 심사를 기다리기 싫으신 경우**: 카카오 심사가 1~3일 걸립니다 (이건 저도 어찌할 수 없습니다)
