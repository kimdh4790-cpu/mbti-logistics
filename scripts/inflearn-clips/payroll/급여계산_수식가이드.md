# 급여계산 Google Sheets 수식 가이드
# (이 파일을 보며 Google Sheets를 직접 만들거나, xlsx 템플릿을 그대로 사용하세요)

## 시트 구성

1. **설정** — 요율·회사정보
2. **급여계산** — 직원별 급여 계산 메인
3. **명세서출력** — A4 출력용 명세서

---

## 1. 설정 시트

| 셀 | 항목 | 값 |
|---|---|---|
| B2 | 회사명 | (직접 입력) |
| B3 | 사업자번호 | (직접 입력) |
| B4 | 당월 | 2026-09 |
| B7 | 국민연금_근로자 | 0.045 |
| B8 | 건강보험_근로자 | 0.03545 |
| B9 | 장기요양_비율 | 0.1295 |

| B13 | 국민연금_사업주 | 0.045 |
| B14 | 건강보험_사업주 | 0.03545 |
| B15 | 고용보험_사업주 | 0.0115 |

## 2. 급여계산 시트 — 열 구성

| 열 | 항목 | 수식 (3행 기준) |
|---|---|---|
| A | 번호 | 1, 2, 3... |
| B | 이름 | (직접 입력) |
| C | 기본급 | (직접 입력) |
| D | 식대 | (직접 입력, 월 20만원 비과세) |
| E | 기타수당 | (직접 입력) |
| F | 부양가족수 | (직접 입력, 기본 1) |
| G | 과세기준액 | `=C3+E3` (식대 제외) |
| H | 국민연금 | `=ROUND(G3*설정!$B$7,0)` |
| I | 건강보험 | `=ROUND(G3*설정!$B$8,0)` |
| J | 장기요양 | `=ROUND(I3*설정!$B$9,0)` |
| K | 고용보험 | `=ROUND(G3*설정!$B$10,0)` |
| L | 근로소득세 | `=IFERROR(VLOOKUP(G3,간이세액표!$A:$H,F3+2,TRUE),0)` |
| M | 지방소득세 | `=ROUND(L3*0.1,0)` |
| N | 총공제액 | `=SUM(H3:M3)` |
| O | 실수령액 | `=C3+D3+E3-N3` |

```
┌─────────────────────────────────┐
│         급 여 명 세 서           │
│  (주) [회사명]       [당월]      │
```

## Sheets 수식 — 명세서출력 시트 (급여계산 시트 연동)

명세서에서 직원 번호(A1)를 입력하면 자동으로 데이터를 가져옵니다:

```
이름:     =INDEX(급여계산!B:B, MATCH(A1, 급여계산!A:A, 0))
기본급:   =INDEX(급여계산!C:C, MATCH(A1, 급여계산!A:A, 0))
식대:     =INDEX(급여계산!D:D, MATCH(A1, 급여계산!A:A, 0))
기타수당: =INDEX(급여계산!E:E, MATCH(A1, 급여계산!A:A, 0))
국민연금: =INDEX(급여계산!H:H, MATCH(A1, 급여계산!A:A, 0))
건강보험: =INDEX(급여계산!I:I, MATCH(A1, 급여계산!A:A, 0))
장기요양: =INDEX(급여계산!J:J, MATCH(A1, 급여계산!A:A, 0))
고용보험: =INDEX(급여계산!K:K, MATCH(A1, 급여계산!A:A, 0))
근로소득세: =INDEX(급여계산!L:L, MATCH(A1, 급여계산!A:A, 0))
지방소득세: =INDEX(급여계산!M:M, MATCH(A1, 급여계산!A:A, 0))
실수령액: =INDEX(급여계산!O:O, MATCH(A1, 급여계산!A:A, 0))
```
