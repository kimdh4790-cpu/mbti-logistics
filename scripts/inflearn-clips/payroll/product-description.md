## 상품 소개

### 이걸 만들게 된 계기

직원 3명 고용한 카페 사장님이 매달 급여일 전날 밤을 이렇게 보냈습니다.

국민연금 4.5%... 건강보험 3.545%... 장기요양은 건강보험료의 12.95%... 고용보험 0.9%...

계산기 두드리다 틀리고, 틀린 금액 이체하고, 다음 달에 또 같은 실수.

이 시트 하나면 **이름·기본급 입력 후 Enter 한 번에 전 항목 자동 계산**됩니다.

---

### 이 템플릿으로 무엇을 할 수 있나요?

**대상 사용자:**
- 직원 1~20명 규모 소상공인·스타트업 대표
- 4대보험 계산이 헷갈리는 경리 담당자
- 매달 급여명세서를 수동으로 만드는 분
- 세무사 없이 직접 급여 정산하는 1인 사업자

### 자동 계산 항목 (2026년 요율 반영)

#### 4대보험 근로자 부담분
| 항목 | 요율 | 계산 예시 (월급 250만원) |
|---|---|---|
| 국민연금 | 4.5% | 112,500원 |
| 건강보험 | 3.545% | 88,625원 |
| 장기요양보험 | 건강보험료 × 12.95% | 11,477원 |
| 고용보험 | 0.9% | 22,500원 |
| **합계** | | **235,102원** |

#### 근로소득세·지방소득세
- 부양가족 수 입력 시 간이세액표 자동 적용
- 지방소득세 = 근로소득세 × 10% 자동 계산

#### 실수령액
- 기본급 + 수당 - 4대보험 - 소득세 - 지방소득세 = **실수령액 자동 표시**

---

### 실제 계산 예시

월 기본급 2,500,000원, 부양가족 1명(본인) 기준:

| 항목 | 금액 |
|---|---|
| 기본급 | 2,500,000원 |
| 국민연금 | -112,500원 |
| 건강보험 | -88,625원 |
| 장기요양 | -11,477원 |
| 고용보험 | -22,500원 |
| 근로소득세 | -45,390원 |
| 지방소득세 | -4,530원 |
| **실수령액** | **2,214,978원** |

### 이 템플릿이 필요 없는 경우

솔직하게 말씀드립니다.

- **직원 20명 이상 규모**: 이 시트는 소규모 최적화입니다. 20명 이상은 더존·ERP 도입이 맞습니다
- **이미 세무사에게 급여 관리를 맡긴 경우**: 세무사가 처리해 주므로 이 시트가 필요 없습니다
- **퇴직금·연차수당·야간수당 자동 계산이 필요한 경우**: 이 버전에는 포함되지 않습니다
