# 직원 급여명세서 자동계산 Google Sheets — 사용 가이드

## 시작하기 (5분 설정)

### 1단계: 파일 업로드

1. [Google 드라이브](https://drive.google.com) 접속
2. 새로 만들기 → 파일 업로드 → `급여계산_템플릿.xlsx` 선택
3. 업로드된 파일 더블클릭 → "Google Sheets로 열기" 클릭

### 2단계: 기본 정보 입력

`설정` 시트에서:
- 회사명
- 사업자번호 (급여명세서 출력용)
- 당월 (예: 2026-09)

### 3단계: 직원 정보 입력

`급여계산` 시트 → 직원 행에 입력:

| 열 | 입력 항목 | 예시 |
|---|---|---|
| B | 직원 이름 | 홍길동 |
| C | 기본급 | 2500000 |
| D | 식대 | 200000 |
| E | 기타수당 | 0 |
| F | 부양가족 수 | 1 |

→ G~N열은 **자동 계산**됩니다 (수정하지 마세요)

## 자동 계산 항목 설명

### 4대보험 (2026년 요율)

| 항목 | 근로자 부담 | 사업주 부담 |
|---|---|---|
| 국민연금 | 4.5% | 4.5% |
| 건강보험 | 3.545% | 3.545% |
| 장기요양보험 | 건강보험료 × 12.95% | 동일 |
| 고용보험 | 0.9% | 1.15% |
| 산재보험 | 없음 | 업종별 상이 |

> 사업주 부담분은 별도 시트에서 확인 가능합니다.

### 근로소득세 간이세액표

부양가족 수에 따라 국세청 간이세액표 기준으로 자동 적용:
- 0명: 독신 기준
- 1명: 본인 1명
- 2명: 배우자 또는 자녀 포함

### 실수령액 계산식

```
실수령액 = 기본급 + 식대 + 기타수당
         - 국민연금 - 건강보험 - 장기요양 - 고용보험
         - 근로소득세 - 지방소득세
```

## 급여명세서 출력

1. `급여계산` 시트에서 해당 직원 행 선택
2. `명세서출력` 시트 클릭 → 자동으로 데이터 반영됨
3. 파일 → 인쇄 → A4 세로 → 인쇄 (또는 PDF 저장)

## 자주 묻는 질문

**Q. 요율이 바뀌면 어떻게 하나요?**  
A. `설정` 시트의 요율 셀만 수정하면 전체 자동 반영됩니다.

**Q. 직원을 추가하려면?**  
A. 기존 직원 행 전체 선택 → 복사 → 아래 행에 붙여넣기 → 이름·금액만 수정.

**Q. 4대보험 정산 신고는 이 시트로 되나요?**  
A. 계산 확인용입니다. 신고는 4대보험 정보연계센터(4insure.or.kr)에서 별도로 하셔야 합니다.

**Q. 시간제 직원(파트타임)도 계산되나요?**  
A. 네. 기본급 란에 시급 × 실근무시간을 입력하시면 됩니다.
