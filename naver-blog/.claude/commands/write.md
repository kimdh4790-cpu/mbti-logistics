# /write — 네이버 블로그 초안 생성 + 임시저장

## 실행 순서

### 1. 사전 확인 (반드시 질문)
- 협찬·체험단 글인가요? (없으면 "내돈내산"으로 표기 생략)
- 메인 키워드가 뭔가요? (지역명 포함 권장)
- 사진은 input/photos/에 넣으셨나요?
- 동영상은 input/videos/에 있나요?
- 지도 첨부할 장소가 있나요? (장소명·검색어)

### 2. 사진 분석
- input/photos/ 의 사진을 Read 툴로 전부 열어 내용 파악
- 개인정보(얼굴·번호판·전화번호) 발견 시 → mosaic_spec.json 생성 → npm run mosaic
- 처리본 확인 후 초안에 처리본 경로 사용

### 3. 페르소나 정의
"[메인 키워드]를 검색하는 1명":
- 지역·나이·직책·상황·감정을 구체적으로 설정
- 이 사람에게 말 걸듯 전체 글 작성

### 4. 초안 JSON 생성 (drafts/YYYYMMDD_제목키워드.json)
필수 구조:
```json
{
  "title": "25~32자 제목",
  "sponsored": false,
  "tags": ["태그1", ..., "태그10"],
  "place": {"query": "검색어", "name": "정확한 장소명"},
  "video": {"path": "input/videos/파일.mp4", "title": "40자 이내 제목"},
  "blocks": [
    {"type": "text", "content": "첫 문단 — Yes-set (2~3문장)"},
    {"type": "text", "content": "둘째 문단 — 권위 한 줄 (authority-lines.md에서 선택)"},
    ...
  ]
}
```

### 5. 글쓰기 공식 체크리스트
- [ ] 메인 키워드: 제목 앞쪽·첫 문단·마지막 문단·본문 5~7회
- [ ] Yes-set: 첫 2~3문장이 페르소나 상황 적중하나?
- [ ] 권위 한 줄: authority-lines.md에서 솔직함형 선택
- [ ] 인용구(quote): 2~4개 배치
- [ ] 구분선(divider): 섹션 구분
- [ ] 소제목(subtitle): 서브 키워드 2~3개 배치
- [ ] 글자 수: 1,800~2,500자 (정보성 최대 3,000자)
- [ ] 사진: 장당 텍스트 2~4문단 배치
- [ ] 500자 연속 텍스트 없음 (리듬 파괴 장치 필수)
- [ ] 업체명 본문 3회 이내
- [ ] 연락처/CTA 글 전체 1회
- [ ] 협찬이면 첫 블록에 표기 문구 (sponsored-disclosure.md)
- [ ] 모바일: 인용구·소제목만 훑어도 핵심 전달되나?

### 6. 사용자 승인 후 임시저장
초안을 보여주고 승인 받은 후에만:
```
npm run draft -- --draft drafts/파일.json
```
dry-run 먼저:
```
npm run draft -- --draft drafts/파일.json --dry-run
```

### 7. 이중 검증
- 스크린샷 확인
- 텍스트 덤프(_dump.txt)와 초안 대조
- 불일치 시 성공 보고 금지 — 원인 찾아 수정

### 8. 발행 후 안내 (스크립트 자동 출력 + 수동 항목만 추가 안내)
- 타겟 활동 시간대에 발행
- 발행 후 24시간 수정 금지
- 주 2~3회 주기 유지
- 협찬 표기 육안 확인
