# 업종별 필수 촬영 컷 가이드

## FILO (매장 관리 앱)
1. 앱 홈 대시보드 전체 화면
2. POS 주문 화면 (테이블 선택)
3. QR 출퇴근 직원 선택 화면
4. 급여명세서 화면
5. 메뉴 관리 그리드
6. 매출 분석 그래프
7. 주방 디스플레이(kitchen.html)
8. 고객 QR주문 화면 (order.html)
9. 재고 현황 화면
10. 매장 설정 화면

## DINE (직원 앱)
1. DINE 로그인/홈 화면
2. 스케줄 캘린더
3. 급여 내역
4. 근태 현황 (출퇴근 기록)
5. 매출 분석

## DONWAY (정산 SaaS)
1. 엑셀 업로드 화면
2. 정산 목록 (기사별 금액)
3. 알림톡 발송 화면
4. 세금계산서 발행 화면
5. 요금제 선택 화면

## 공통 촬영 원칙
- 실제 데이터 화면 (더미 데이터 권장 — 개인정보 노출 금지)
- 세로 스마트폰 화면 위주 (모바일 앱)
- 화면 글씨 선명하게 (흐리면 가치 없음)
- 타인 얼굴·번호판 노출 시 mosaic.js 처리 필수
- 화자 본인 얼굴도 기본 모자이크 (공개 명시 시 예외)
