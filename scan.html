이력서 분석

  • 직무 키워드 매칭률 자동 채점 (0~100점)
  • 경력·학력·스킬셋 항목별 피드백
  • 채용공고 JD 기반 맞춤 분석 (선택)
  • 개선 문구 샘플 자동 생성
  • HWP · DOCX · PDF 모든 형식 지원

자기소개서 첨삭

  • 문항별 STAR 구조 분석
  • 어휘 다양성·문장 가독성 점수
  • 중복 표현·진부한 표현 감지
  • 분량 최적화 제안
  • 합격률 높은 표현으로 재작성 제안

계약서 검토

  • 불리한 조항 자동 하이라이트
  • 표준 계약서 대비 누락 항목 감지
  • 위약금·해지 조건·갱신 조건 요약
  • 법적 리스크 등급 (낮음/중간/높음)
  • 수정 권장 문구 제안

면접 질문 생성

  • 이력서 기반 맞춤 예상 질문 10~20개
  • 질문 유형 분류 (직무/경험/성격/압박)
  • 취약 포인트 파악 및 대비 전략
  • 모범 답변 구조 (STAR 방식) 제안
  • 공고 JD 연계 심층 면접 예측 지원

공문서 발급·분석

  • 등기부등본: 주소 입력 → 인터넷등기소 연결
  • 사업자등록: 국세청 API 즉시 조회
  • 건강보험·소득증명: 기관 딥링크 제공
  • 발급 문서 AI 해설 (갑구·을구·근저당 등)
  • Tilko API 연동 등기부 직접 조회 지원

범용 문서 분석

  • HWP · DOCX · PDF · TXT 전 형식 지원
  • 핵심 내용 3줄 요약 자동 생성
  • 문서 유형 자동 감지
  • 개선 포인트·오류 자동 탐지
  • Oracle 서버 LibreOffice 변환 지원
